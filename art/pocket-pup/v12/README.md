# Cute Tongue Out Expressions

[Full dogs and face details](tongue-out-options.png) show four tongue-out alternatives on the selected v9 fur-details dog: tiny blep, a longer central tongue, a side blep, and a happy pant with closed smiling eyes. The tiny blep keeps the C14 smile largely intact.

Each native PNG is transparent 64 by 64. Body, fur details, nose, silhouette, and clothing anchors are preserved. No v10/v11 muzzle treatment was assumed selected. The [tiny blep preview](tiny-blep-preview.gif) alternates neutral and blep stills; it is not a complete tongue animation cycle.

Rebuild with `python tools/pocket_pup/tongue_study.py`. Validation checks the dimensions, alpha silhouette, changes confined to the expression area, and code-size limits. No application sprites or state are replaced.
