# Walking reference concepts

These are review-only animation studies; they are not runtime art and have not been approved.

- `walk-entrance-preview.gif` and `walk-pose-sheet.png`: scripted study using v33/neutral-0.png, with cropped and moved paws. It demonstrates timing but can detach outlines and slide.
- `generated-reference-sheet.png`: image-generated visual reference based on the v33 sprite and the rough pose sheet. It is not pixel-matched to the approved art.
- `generated-walk-concept.gif`: eight generated sheet panels sequenced at 150 ms each for motion discussion. It is not a fitted sprite or validated seamless loop.

For production, use the approved `v32/00.png` neutral frame as the endpoint. Draw connected limbs and grounded steps on the 64×64 grid, preserve the existing head, palette, silhouette and separate wearable layers, and review poses, motion and timing before integration. Check transparent edges, fit equipment and reduced motion.
