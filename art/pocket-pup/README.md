## Drawing and export agreements

- Every sprite and overlay is an RGBA PNG on a 64 by 64 canvas.
- Top-left is the origin. Ground is row 55; standing neck anchor is (22,42), head reference is (20,28).
- Idle, happy, tired, barking, and blink share an identical silhouette and clothing anchors.
- Sleeping is a separate lowered pose. The included bandana is not fitted to it.
- Base coat uses eight fixed colors. Expressions and accessories add colors from the manifest palette.
- Alpha is binary: 0 or 255. There is no partial transparency or anti-aliasing in native exports.
- Enlarge using nearest-neighbor at integer multiples: 128, 192, or 256 pixels. Avoid scaling the 64-pixel frame to 160 pixels if equal-sized screen pixels matter.
- Composite dog, compatible accessory, then optional effect marks. The base image never contains the bandana or wag marks.

The base is a palette-limited conversion of the selected generated concept; face patches, sleeping construction, bandana, and marks are authored with integer pixel operations. This is not a newly generated expression sheet or an exact hand redraw of every source pixel.

## Rebuild

Use Python 3.10 or newer and Pillow:

```sh
python -m pip install -r tools/pocket_pup/requirements.txt
python tools/pocket_pup/build.py
```

The checked-in source board makes the build reproducible without access to chat attachments. The default rebuild writes version six. The generator validates dimensions, alpha, palette, standing silhouettes, face-only changes, nose/mouth separation, and its own file/function sizes. It does not modify application source or saves.
