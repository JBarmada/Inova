# Fluffy-chest sitting study

[Comparison](sitting-comparison.png) and [transparent sprite](sitting-fluffy.png).

Follows the latest user-supplied corgi reference for a broad fluffy cream bib, longer front legs, and a three-quarter seated body. Keeps the selected Pocket Pup head/face, original palette, and curled tail. The supplied image is posture guidance only and is not bundled. No toe lines are added.

The cleaned head is translated two pixels right and five pixels up. New body, cream bib, and paws are drawn together on the 64 by 64 pixel grid. This remains an unselected review draft; clothing fitting and app integration are unfinished. Transition animation remains paused.

Rebuild with `python tools/pocket_pup/fluffy_sit.py` using Pillow. Validation checks face pixels, dimensions, transparency, ground height, and source size limits; visual approval remains with the user.
