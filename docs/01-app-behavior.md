# What the App Will Do

Working behavior draft. This describes the intended experience; it is not a claim that any feature is built. Delivery priorities are listed separately.

# First visit

1. Enter a playful pixel adoption center.
2. Browse a lightweight wardrobe-style picker with a small selection of base dogs.
3. Preview a dog, choose it, and give it a name.
4. Meet the adopted dog with an animation, bark, and adoption confirmation.
5. Choose a growth goal and encouragement preferences. Add initial commitments manually.
6. Move into the everyday desktop companion experience.

# Everyday companion

- A small pixel dog sits above other desktop windows with a transparent background.
- The user can drag it to a preferred position.
- Selecting the dog opens its interactions and access to quests, wardrobe, and memories.
- Larger screens such as adoption, wardrobe, and the memory room open when needed.
- Every deliberate user action produces an appropriate visible response and, when sound is enabled, an appropriate sound.

The floating desktop companion is the intended product direction. Desktop operating system and implementation approach are still open. An in-browser dog alone would not satisfy the desktop overlay goal.

# Growth loop

1. The companion uses commitments, goals, and relevant approved memories to suggest small quests.
2. The user accepts, edits, or dismisses a suggestion.
3. The user completes an activity or reflects on what happened.
4. The app records the experience and applies the selected reward rule once.
5. An unlock produces a celebration. The user can equip a cosmetic or use an unlocked interaction item.
6. The companion uses relevant feedback to improve later suggestions.

# Returning later

The adopted dog, equipped items, earned unlocks, and saved memories persist between visits. A return after an absence welcomes the user back. Exact reminder frequency and the optional spooky mode remain undecided.
