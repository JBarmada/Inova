# What We Want to Reach for Sure

Proposed minimum delivery scope based on the team's stated direction. Pixel art, strong game feel, and the floating desktop dog are established preferences. The exact delivery boundary still depends on team capacity and deadline.

# Minimum complete experience

| Priority | Required outcome | Observable completion |
| --- | --- | --- |
| M1 | Pixel dog adoption | A user chooses and names a dog in an adoption-center flow |
| M2 | Floating desktop companion | The transparent dog appears above other windows and can be dragged |
| M3 | Expressive dog | The dog has idle and contrasting emotion reactions |
| M4 | Layered customization | Equip and remove an unlocked cosmetic without replacing the whole dog image |
| M5 | Commitments and quests | Add a commitment manually and accept or edit an actionable AI suggestion |
| M6 | Experience-based reward | Record a completed experience, award once, and reveal a related item |
| M7 | Game feedback | Every implemented deliberate action has visual feedback and an appropriate sound when enabled |
| M8 | Short reflection and adaptation | Save a reflection or preference and demonstrate a relevant later suggestion using it |
| M9 | Visible memory | Open a dated memory book from a simple bookshelf |
| M10 | Persistence and control | Dog, equipment, rewards, and memories survive a restart; user can mute and manage memory |
| M11 | Recovery | Missing data or a failed AI response produces a readable fallback without losing progress |

# One complete demo

Adopt a dog, drag it over another desktop window, add a commitment, receive a small quest, complete it, hear the celebration, equip its reward, and open the resulting dated memory. Return to a later planning interaction to show that saved feedback changes the suggestion.

# Bound the content

The minimum can use one finished base dog, a few states, a tiny item collection, and one bookshelf. Multiple dog choices remain desired, but the count should not block proving the full experience.

An external account integration is outside this proposed minimum. Manual commitments can support the first demonstration. The desktop overlay itself is central and needs an early feasibility milestone on the selected operating system.

# Build order proposal

1. Prove a transparent movable dog above desktop windows.
2. Complete adoption, basic reactions, layered equipment, and sounds.
3. Connect manual commitments to a quest and reward.
4. Add reflection, persistence, and a simple bookshelf.
5. Demonstrate personalization and recovery, then polish the complete flow.
