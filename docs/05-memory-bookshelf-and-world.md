# Memory Bookshelf and Expanding World

Desired experience: the dog has an explorable pixel world that grows alongside the user. The memory bookshelf is the first concrete place proposed for that world.

# Memory bookshelf

- The user opens a library or memory room and sees a bookshelf.
- Book spines display dates.
- Selecting a book opens the corresponding memory.
- The open book presents readable writing, with more space than the spine.
- The memory is both a personal record the user can revisit and a possible source of context for the companion.
- Book interactions use appropriate opening, closing, and page sounds.

Whether a book represents one day, one entry, or a collection is undecided.

# Proposed memory contents

A memory can include a date, short title, the user's original reflection, related experiences or quests, and an optional summary. Show a summary as a summary, preserving the original writing separately.

A user should be able to edit or delete an entry and control whether it informs the companion. Being visible on the bookshelf should not automatically make every private entry available for personalization.

# What the dog remembers

When a suggestion uses a memory, let the user inspect the relevant record. Ask before treating an inferred pattern as a lasting preference. Removing a memory from personalization must also remove its influence from maintained summaries and retrieval copies.

# Growth of the world

Possible unlocks include books, shelf decorations, furniture, doors, and new rooms. Tie a reward to the experience that earned it and explain the connection.

Example proposal: a completed learning quest unlocks a notebook prop and adds a dated memory. A later exploration milestone reveals a new location. The exact earning rules are still open.

# Smallest useful version

One bookshelf view with dated selectable books and one readable open-book view demonstrates the idea. Start with ordinary text; photo memories, search, multiple rooms, and a larger explorable world can follow.

# Readability checks

Dates remain legible, long entries can be read comfortably, and the user can close the book and return to the shelf. A muted user receives the same navigational information through visual feedback.
