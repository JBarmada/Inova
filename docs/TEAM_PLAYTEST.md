# Inova team playtest

## Team priorities

- Windows and Mac desktop playtesting
- Adoption, quests, and rewards
- Floating dog and quest toy
- Wardrobe and outfit quest feedback
- Demo walkthrough and bug triage

## Start here

1. Set up GitHub access, open the Inova repo in Codex, and paste the prompt below. Tell Chat whether you use Windows or Mac.
2. Ask Chat to help you launch Inova one step at a time. The repo’s README and `docs/SETUP.md` have the setup steps. From the repo folder, the desktop commands are `npm ci` and then `npm run desktop`. If a step fails, share the exact error with Chat.
3. Spend 10 minutes trying one flow below. Use a made-up dog name and fictional entries.
4. Tap the mic and talk through what happened. Say what you clicked, what you expected, what happened, and why it felt confusing or awkward. Include what worked. Add a screenshot if it helps.
5. Ask Chat to turn your notes into up to three bullets. Include your OS, desktop or browser, and the steps for any bug. Share those bullets in the team chat.

## Pick one flow

- **First run:** Adopt and name your dog. See if you can find Quests, Wardrobe, and Memories without help.
- **Quests:** Tell Inu a fictional goal in chat and review the suggested plan. Accept and complete a quest. Look for clear feedback about completion and any reward.
- **Floating dog:** In the desktop app, drag the dog and switch to another app. Open the quest toy and click outside it. Check whether the dog stays visible and the menu dismisses. If you use the browser preview, mark this flow as untested.
- **Wardrobe:** Try an available item, switch between Stand and Sit, and clear the outfit. If you can’t tell how to unlock an item, describe what would make that clearer. The outfit chat is already working on outfit quests and wardrobe improvements, so send those observations to that effort.

## Paste this into Chat

> Read `docs/TEAM_PLAYTEST.md` in the Inova GitHub repo. Help me open the app one step at a time and pick one thing to test. After I try it, help me turn my feedback into 1–3 bullets I can share with the team.

Example voice note

> I’m on Mac in the desktop app. I opened Wardrobe after finishing a fictional quest and tapped a locked hat. I expected to see how to earn it. I could tell it was locked, but I couldn’t tell what to do next. I’d like the unlock requirement beside the hat.
