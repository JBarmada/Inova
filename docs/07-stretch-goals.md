# What We Hope to Reach if Possible

Stretch backlog. These items matter to the vision but should not prevent completion of the minimum experience.

# First additions after the core works

- More base dogs in the adoption picker.
- Treat and toy interactions with animations and sound.
- More cosmetic slots and compatible items.
- Optional random outfits assembled from owned items.
- A richer memory room with animated books and shelf decorations.
- A single useful calendar or assignment integration, after verifying access.

# Growth and personalization

- Weekly recaps tied to actual recorded experiences.
- Monthly exploration suggestions matched to interests, available time, and desired challenge.
- Practical adulting conversations and checklists.
- Optional perspective exercises and discussion with evidence for factual claims.
- More sophisticated scheduling and approved calendar changes.
- Better personalization of encouragement, reminder timing, and quest size.

# World and secrets

- New rooms and locations unlocked through experiences.
- More ways for the dog to play and react.
- Optional eye-bag appearance after a user reports an all-nighter.
- Secret zombie or skeleton appearances.
- A revival potion or a lightning transformation scene.
- A more extensive evolution animation sequence.

The spooky mode is exploratory. Automatic transformation after missed commitments and revival earned through renewed commitment were suggested, but are not finalized.

# Integrations to investigate separately

| Candidate | Intended benefit | Question to resolve first |
| --- | --- | --- |
| Brightspace | Assignment and academic context | What permitted access is available for the intended users? |
| Calendar | Understand commitments and availability | Which provider and permissions will the team support? |
| Sleep source | Adapt suggestions to reported or recorded rest | Is manual check-in sufficient for the intended use? |
| App activity | Optional awareness of selected activity patterns | What can the chosen platform access with user permission? |
| Photo entries | Add personal context to memories | What user benefit justifies storage and interpretation? |

# Order of selection

Finish the complete core loop first. Choose additions by how much they strengthen attachment, useful support, or the shared-growth theme relative to their implementation effort. Keep integration failures from blocking manual use.
